# 节点备注

给节点记备注；每分钟数一次离线节点，超过阈值发一次通知。也是 DStatus 插件样板：每样能力用了一次，复制改名就能开始写自己的插件。

> 这份 README 也是插件说明的写法示例：投稿的插件都要有一份，写清下面这几节。

## 功能

- 后台页面「节点备注」：列出全部节点与备注，可以改、删备注，可以手动统计一次离线节点。
- 每分钟统计离线节点；离线数超过阈值时发一次通知，恢复到阈值以下后可以再次提醒。
- AI 助手与 MCP 工具：读取备注、写备注（先预览再执行）、统计离线节点。

## 权限与用途

| 权限 | 用途 |
|---|---|
| `storage` | 保存备注（按节点存，节点删除时主控连带删掉） |
| `nodes:read` | 读节点名称与在线状态 |
| `timers` | 每分钟统计一次离线节点 |
| `notify` | 离线超过阈值时发通知（事件「离线节点超过阈值」，发不发、发到哪由站长在通知规则里定） |
| `http:admin` | 后台接口，页面经它读写备注 |
| `pages` | 后台页面「节点备注」 |
| `tools` | 三个 AI / MCP 工具；写备注的工具需要站长批准，执行前要确认 |

## 设置

插件卡片里的设置表单：离线阈值（台，缺省 3）、是否发通知（缺省发）。

## 数据

- 存储：每个节点一条备注（≤ 200 字）。不保存节点的其他信息。
- 卸载时默认保留备注，重装后还在；站长卸载时可以选择一并删除。

## 外部服务

无。插件不访问任何外部地址。
